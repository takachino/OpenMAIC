# 機能

> 生成: OpenCode + DeepSeek V4.1 Flash Free（2026-11-02）

## 授業の生成

ホーム画面でテーマを入力するか、資料を添付して生成を開始します。
入力できる資料は PDF、Word、PowerPoint、表計算、テキスト、画像、音声、動画です。
対応形式は設定した抽出器に依存します。

生成は 2 段階です。

| 段階 | 内容 |
| --- | --- |
| 構成案 | 入力と資料を分析し、対象者、目的、章立て、各ページの役割を決める |
| シーン | 構成案の各項目を、スライド、クイズ、インタラクティブ、PBL のいずれかに変換する |

構成案は生成の途中で確認でき、必要なら修正してから先へ進めます。
生成はサーバー側で進むため、タブを閉じても処理は継続します。

### ナレッジベース

1.3.0 で、アップロードした資料はオーナーのナレッジベースに保管されるようになりました。

- 資料は削除するまで残る。
- フォルダで整理できる。
- 最初の添付時に一度だけ解析され、その結果を何度も再利用できる。
- 入力欄で `@` を打つと、資料を会話の参照として指定できる。
- エージェントは資料の読み取り、検索、整理を行える。

以前のバージョンのように、生成のたびに同じ PDF を解析し直す必要はありません。

## シーンの種類

| 種類 | 内容 | 書き出し時の扱い |
| --- | --- | --- |
| `slide` | スライド。テキスト、画像、図形、表、グラフ、数式を配置する | PPTX の編集可能なスライドになる |
| `quiz` | 単一選択、複数選択、短答。AI が採点してフィードバックする | プレースホルダーのスライドとオンライン参加用の QR コードになる |
| `interactive` | HTML で作るシミュレーション、3D、ゲーム、マインドマップ、プログラミング | リソースパックでは独立した Web ページ、オフライン HTML では埋め込み |
| `pbl` | 役割を選び、マイルストーンと成果物を伴うプロジェクト型学習 | プレースホルダーのスライドとオンライン参加用の QR コードになる |

シーンは 1 つのコースに混在できます。
講義のあとにクイズを置き、理解が浅い箇所をシミュレーションで補い、最後に PBL で手を動かす、といった構成が作れます。

## 教室での体験

### 講義

AI 教師がナレーションを読み上げ、スライドの注目箇所をスポットライトで照らし、レーザーポインタで指し示します。
発話は字幕としても表示されます。

### ホワイトボード

エージェントは共有のホワイトボードに図を描けます。
数式を 1 段ずつ解いたり、フローチャートを描いたり、概念を図解したりします。
描画は SVG ベースで、再生中の学習者にも同じタイミングで見えます。

### 対話

- **教室での議論**：エージェントが議論を始め、学習者はいつでも参加できる。指名されることもある。
- **ラウンドテーブル**：異なるペルソナの複数エージェントが討論する。
- **Q&A**：自由に質問すると、AI 教師がスライド、図、ホワイトボードで答える。

1.2.1 以降、教室チャットは常に Pi 上で動きます。
そのため `classroom` スロットには、ツール呼び出しに対応したモデルが必要です。

### 音声

TTS による読み上げと、マイクからの音声認識に対応します。
声はプロバイダーごとに選べ、VoxCPM2 を使う場合は声のクローンもできます。
読み上げは講座の言語で行います。声で言語が決まるプロバイダー (Kokoro、Azure) では、講座の言語の声を選びます。
サーバー側の TTS で音声のない行は、ブラウザの読み上げで読みます。

## Deep Interactive Mode

通常の生成が「見て学ぶ」授業を作るのに対し、Deep Interactive Mode は「触って学ぶ」教材を作ります。
学習者は実験の条件を変え、シミュレーションの結果を観察し、ゲームで知識を確かめます。

対応する UI は 5 種類です。

| 種類 | 例 |
| --- | --- |
| 3D ビジュアライゼーション | 立体的な構造の表示、回転や拡大 |
| シミュレーション | 物理現象、化学反応、フローチャートの動的実行 |
| ゲーム | 知識を問うミニゲーム、パズル |
| マインドマップ | 概念の階層整理、関係の可視化 |
| オンラインプログラミング | ブラウザ内でのコード記述と実行 |

AI 教師は教材を操作できます。
注目すべき箇所を強調し、条件を設定し、ヒントを出し、適切なタイミングで学習者の注意を導きます。

生成された UI はレスポンシブで、デスクトップ、タブレット、スマートフォンで動きます。
より高度な教育 UI の生成が必要な場合は、姉妹プロジェクトの [MAIC-UI](https://github.com/THU-MAIC/MAIC-UI) が案内されています。

## エージェントワークベンチ

Pro ワークベンチは、会話しながらコースを組み立てる画面です。
ホーム画面の Pro から入ります。

### セッションの性質

- セッションは PostgreSQL に保存され、ワーカーが再起動しても再開できる。
- 実行中でも追加の指示を受け付けられる。
- イベント履歴を再生できる形でストリームする。
- リース、ハートビート、クラッシュからの復帰、キャンセルに対応する。

### エージェントが使える操作

| 領域 | 内容 |
| --- | --- |
| 計画 | 複数回の授業からなるカリキュラムを計画する。コースとフォルダを作成、名前変更、移動する |
| 構築と編集 | ステージ DSL を読み、検索し、1 つのシーンを原子的に修正する。ページの生成、複製、挿入、削除、並べ替え。ナレーションと構成の編集 |
| 素材 | ファイルをアップロードし、文書、音声、動画を抽出する。抽出済みテキストを検索する。信頼できる URL を取得する。素材メディアを再利用する |
| メディア生成 | 設定済みのプロバイダーで画像と動画を生成する。ナレーション音声を生成する |
| 取り込みと確認 | レイアウトを保ったまま PPTX を取り込む。可能な場合はシーンのプレビューを描画して目視確認する |
| 教室設定 | 利用可能な声を一覧する。エージェントの顔ぶれを決める。登録アダプターがあれば声をクローンして登録する |

### スキル

`skills/agent-runtime/` には 24 個の組み込みスキルがあります。
カリキュラム設計、深い調査、インタラクティブ、講義、ワークショップ、職業教育、スライド制作、ステージ DSL、PPTX インポート、編集、スタイル再利用などをカバーします。

利用者が作ったスキルはオーナーごとに保存され、同じランタイムから作成、読み取り、修正できます。

### Learn と Edit

教室のタブは、学習用の Learn と編集用の Edit を切り替えられます。
切り替えはコースごとにブラウザへ記憶されます。
従来の生成処理がまだコースを作っている間は、編集を開けません。

リクエストの最初のページができるまでは、右ペインにエージェントの作業内容が表示されます。
何を理解し、何を調べ、どこで質問し、どのように顔ぶれを組んでいるかが見えます。
最初のページができると、Learn モードのコースへ引き継がれます。

## 書き出し

| 形式 | 内容 |
| --- | --- |
| PowerPoint（`.pptx`） | 画像、グラフ、LaTeX 数式を含む編集可能なスライド。インタラクティブ、クイズ、PBL は「オンラインで開く」ボタンと QR コード付きのプレースホルダーになる |
| リソースパック | PPTX と、各インタラクティブシーンを独立した Web ページにしたもの |
| オフライン HTML | ネットワークなしで教室全体を再生する 1 ファイル。ナレーション、字幕、スポットライト、レーザー、スライド動画、クイズ、インタラクティブを含む。ナレーションの有無を選べる |
| 教室 ZIP | コース構造とメディアを含む完全なバックアップ。別のデプロイへの移動にも使える |
| MP4 動画 | `render-service` がある場合に、ブラウザで組んだ Hyperframes プロジェクトを動画化する |

オフライン用の書き出しでは、インタラクティブシーンが参照する外部資産（KaTeX、Three.js、Tailwind CDN、Google Fonts、画像）を `data:` URI として HTML に埋め込みます。
そのため、エアギャップ環境やイントラネットへ取り込んでも、再生時に公開 CDN へ接続しません。
取得できなかった資産は URL のまま残り、報告されます。
この機能より前に書き出した教室は CDN を参照するため、再度書き出す必要があります。

400 MB を超える教室は ZIP として保存されます。
インポートした ZIP の音声、画像、動画、ポスターはサーバーのアセットプールに格納されるため、別のブラウザでも解決できます。

## 外部エージェントとの連携

`skills/openmaic/` は SKILL.md 形式のスキルパッケージです。
OpenClaw、Codex、DeepSeek、WorkBuddy などのエージェントワークベンチから読み込めます。

- **ホスト版**：`open.maic.chat` でアクセスコードを取得し、設定に保存すればローカル環境なしで教室を生成できる。
- **セルフホスト版**：クローン、依存関係のインストール、API キーの設定、サーバー起動を順に案内する。
- **進捗確認**：非同期の生成ジョブをポーリングし、完了したらリンクを返す。
- **二次開発**：`@openmaic/*` SDK を使った独自アプリの作り方を案内する。

OpenClaw では ClawHub から 1 コマンドで導入できます。

```bash
clawhub install openmaic
```

スキルは各手順の前に確認を求めます。
設定は `~/.openclaw/openclaw.json` の `skills.entries.openmaic.config` に置きます。

## UI と言語

- **12 ロケール（11 言語）**：簡体字中国語、繁体字中国語、英語、日本語、韓国語、ロシア語、アラビア語、ポルトガル語（ブラジル）、スペイン語（メキシコ）、フランス語、ベトナム語、ドイツ語。
- **ダークモード**：夜間の学習向けに配色を切り替えられる。
- **レスポンシブ**：ホーム画面と教室はスマートフォンにも対応する。
- **キーボード操作**：再生や編集のためのショートカットがある。

## feature flag

主なフラグを整理します。
`NEXT_PUBLIC_*` はビルド時に埋め込まれるため、変更には再ビルドが必要です。

| 変数 | 既定 | 効果 |
| --- | --- | --- |
| `NEXT_PUBLIC_PRO_WORKBENCH_ENABLED` | 無効 | Pro ワークベンチの入口を有効にする。エージェントランタイムも必要 |
| `OPENMAIC_AGENT_RUNTIME_ENABLED` | 無効 | サーバー側の耐久エージェントセッションを有効にする |
| `NEXT_PUBLIC_MAIC_EDITOR_ENABLED` | 無効 | 教室エディターの入口を有効にする。Pro ワークベンチを有効にすると含まれる |
| `NEXT_PUBLIC_MAIC_EDITOR_RENDERER_ENABLED` | 無効 | Pro モードで `@openmaic/editor` を使う |
| `NEXT_PUBLIC_MAIC_PLAYBACK_RENDERER_ENABLED` | 無効 | 教室の再生に `@openmaic/renderer` を使う |
| `NEXT_PUBLIC_COURSEWARE_REFERENCE_ENABLED` | 無効 | Pi の再生で教材参照の統合入口を有効にする |
| `NEXT_PUBLIC_ENABLE_VIDEO_EXPORT` | 無効 | 動画書き出しの入口を表示する |
| `NEXT_PUBLIC_ENABLE_PPTX_IMPORT` | 無効 | PPTX インポートの入口を表示する |
| `OPENMAIC_ENABLE_VOCATIONAL` | 無効 | 職業教育タスクエンジンの生成経路を有効にする |

## 機能の限界

- **生成の品質はモデルに依存する**：構成案の質、ツール呼び出しの安定性、長い文脈の扱いは、選んだモデルで変わります。
- **サーバーレスでは動かない**：生成とエージェントセッションがプロセスを超えて続くため、常駐プロセスが必要です。
- **クラウド解析はデータを外へ出す**：MinerU Cloud や AliDocMind を使うと、資料の内容が外部サービスへ送られます。
  自前ホストかローカル抽出を選べる構成にしてください。
- **ブラウザの保存範囲**：設定、再生位置、キャッシュだけが端末に残ります。
  「ローカルキャッシュを消去」はサーバーのデータを消しません。
- **アクセスコードは認証ではない**：`ACCESS_CODE` はデプロイ全体の合言葉であり、個人の識別は行いません。
  個人単位の権限が必要なら、独自の認証メソッドを登録します。
