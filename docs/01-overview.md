# OpenMAIC の概要

> 生成: OpenCode + DeepSeek V4.1 Flash Free（2026-11-02）

## OpenMAIC が解く課題

教材を作る作業は、調べる、構成を考える、スライドを作る、問題を用意する、説明を書く、という複数の工程に分かれます。
OpenMAIC はこの一連の工程を、テーマの入力または資料の添付から始まる 1 本の生成処理にまとめます。
出来上がるのは静的なスライド集ではなく、AI 教師と AI クラスメートが進行する「教室」です。

OpenMAIC という名前は **Open Multi-Agent Interactive Classroom** の頭文字です。
複数のエージェントが役割を分担して授業を組み立て、再生時にも学習者と対話する点が、単発のスライド生成ツールとの違いです。

## できること

- **授業の一括生成**：テーマを書くか資料を添付すると、構成案から各ページの内容までを生成する。
- **マルチエージェントの教室**：AI 教師と複数の AI クラスメートが講義、議論、ラウンドテーブル、Q&A を行う。
- **複数種のシーン**：スライド、クイズ、インタラクティブな HTML 教材、PBL を 1 つのコースに混在させられる。
- **音声とホワイトボード**：ナレーションの読み上げ、図や数式の描画、スポットライトやレーザーポインタの演出。
- **持ち出し可能な成果物**：PPTX、オフライン HTML、リソースパック、教室 ZIP、MP4 動画として書き出せる。
- **外部エージェントとの連携**：`skills/openmaic/` の Skill を通じ、OpenClaw、Codex、DeepSeek、WorkBuddy などから教室を生成できる。
- **12 ロケールの UI**：簡体字中国語、繁体字中国語、英語、日本語、韓国語、ロシア語、アラビア語、ポルトガル語（ブラジル）、スペイン語（メキシコ）、フランス語、ベトナム語、ドイツ語に対応する。

## 設計の考え方

OpenMAIC の構成は、次の 4 つの分離で理解できます。

**生成と再生の分離**：授業は「ステージ（コース）」と「シーン（ページ）」のデータとして保存され、再生側はそのデータを解釈して動作します。
生成処理が終わったあとに再生エンジンが動くため、生成と再生を別々に改善できます。

**モデルと製品機能の分離**：LLM、画像生成、動画生成、TTS、ASR、Web 検索、文書解析は「スロット」という単位で設定します。
特定ベンダーをコードに埋め込まず、`openmaic.yml` のプロバイダー定義を通じて差し替えます。

**サーバーとブラウザの分離**：コース、履歴、学習者の状態、生成したメディアは PostgreSQL に保存します。
ブラウザには設定や再生位置など、その端末に属する情報だけを残します。

**オーナー単位の分離**：すべてのリクエストは「オーナー」に解決され、オーナーごとにコースライブラリが分かれます。
個人利用、チーム共有、匿名ブラウザ、独自認証の 4 つのモードから選べます。

## 用語

**ステージ（Stage）**：1 つのコース全体を表すデータです。
コースのメタ情報とシーンの並びを持ちます。

**シーン（Scene）**：教室の 1 ページに相当します。
`slide`、`quiz`、`interactive`、`pbl` の 4 種類があります。

**アクション（Action）**：シーンの中でエージェントが行う操作です。
発話、ホワイトボードへの描画、スポットライト、レーザーなどがあります。

**エージェント（Agent）**：AI 教師または AI クラスメートです。
ペルソナ、声、担当する役割を持ちます。

**スロット（Slot）**：AI の用途ごとの設定単位です。
`llm`、`course.outline`、`tts`、`image` などがあり、未設定のスロットは親スロットの設定を継承します。

**オーナー（Owner）**：コースの所有者です。
ブラウザの匿名 Cookie、共有チーム ID、固定の単一ユーザー、独自認証のアカウントのいずれかになります。

**ナレッジベース**：1.3.0 で導入された、アップロード資料の保管場所です。
資料は削除するまでオーナーのもとに残り、フォルダで整理され、一度だけ解析されます。

**Pi**：教室の進行を担うサーバー側のディレクターです。
各ターンを `call_agent` でエージェントに渡し、発話や描画を組み立てます。

## 利用シナリオ

- **自学自習**：学びたいテーマを入力し、AI 教師の講義とクイズで理解を確認する。
- **資料の教材化**：PDF、Word、PowerPoint、表計算、画像、音声、動画から教室を作る。
- **授業の下書き**：教員が構成案とスライドのたたき台を作り、PPTX に書き出して手を加える。
- **研修やワークショップ**：PBL やワークショップ型の進行をエージェントに任せる。
- **プロダクトへの組み込み**：`@openmaic/*` パッケージや HTTP API を使って独自アプリに教室機能を載せる。

## 制約と注意点

- **PostgreSQL が必須**：`DATABASE_URL` がないとサーバーは起動しません。
  1.2.0 以降、コースはサーバー側に保存されます。
- **長時間稼働するプロセスが必要**：生成はリクエストを超えて継続するため、サーバーレス環境では動きません。
  Vercel で動かせるのは 1.1.x までです。
- **モデルの既定値は同梱されない**：`openmaic.yml`、`DEFAULT_MODEL`、または画面のモデル設定のいずれかでモデルを指定しないと、生成は失敗します。
- **アクセス制御は任意**：`ACCESS_CODE` を設定しない場合、到達できる人は誰でもライブラリを読み書きできます。
  ネットワークに公開する前に設定してください。
- **一部の機能は既定で無効**：Pro ワークベンチ、エージェントランタイム、MP4 書き出し、PPTX インポートは feature flag または追加サービスで有効にします。
